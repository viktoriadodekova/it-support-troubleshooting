INC-003 High Priority

NETWORK / ACCESS

VPN connection fails after password change

A remote user cannot establish a company VPN connection after changing their account password.

Environment Windows 11 / VPN
Impact Remote access unavailable
Status Resolved
INC-003 Resolved

ROOT CAUSE

Cached VPN credentials

The VPN client continued attempting authentication with previously stored credentials after the user's password was changed.

RESOLUTION

  • Confirmed general internet connectivity
  • Verified the new account password
  • Cleared stored VPN credentials
  • Re-entered current credentials
  • Completed authentication successfully

VERIFICATION

VPN connection was established successfully and access to the simulated internal environment was confirmed.
